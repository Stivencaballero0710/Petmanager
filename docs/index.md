# PetManager

**Proyecto final de Bases de Datos I | Universidad Industrial de Santander**

PetManager organiza los datos de clientes, mascotas, personal, historiales clínicos, inventarios, sucursales y facturación de una clínica veterinaria.

- [Implementación en SQL](https://github.com/Stivencaballero0710/Petmanager/tree/main/SQL)
- [Sustentación del proyecto](https://github.com/Stivencaballero0710/Petmanager/tree/main/Sustentaci%C3%B3n)

## Implementación

La base de datos tiene **18 tablas**, **17 claves foráneas** y **230 registros**. Las diez consultas SQL permiten recuperar información administrativa y clínica.
