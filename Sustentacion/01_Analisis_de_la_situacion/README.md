## Problema que se busca resolver

Una clínica veterinaria maneja información de clientes, animales, personal, atención clínica, medicamentos, inventario y facturas. Con registros dispersos resulta más difícil mantener relaciones claras entre propietarios, pacientes y atenciones, y pueden aparecer duplicaciones o inconsistencias.

PetManager propone **organizar esa información mediante un modelo relacional**, relacionando los datos de identificación, atención y administración que aparecen en el diseño de la base de datos.

## Explicación breve sugerida

> PetManager nace de la necesidad de manejar en un mismo sistema la información de una veterinaria. Si los datos de clientes, animales, citas, historiales e inventarios están dispersos, consultar y relacionar la información se vuelve más complicado. Por eso, planteamos una base de datos relacional que permita organizar esos registros y mantener sus relaciones. A partir de este problema construimos el modelo entidad-relación que presentamos a continuación.
