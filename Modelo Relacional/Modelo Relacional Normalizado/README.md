# Modelo Relacional Normalizado

Esta carpeta contiene el modelo relacional normalizado del proyecto **PetManager**.

## Contenido

- **Modelo_Relacional_Normalizado.png**: diagrama del modelo relacional normalizado del sistema.

## Descripción

El modelo relacional representa la información del sistema PetManager mediante tablas, atributos, claves primarias y claves foráneas.

El modelo fue revisado mediante el proceso de normalización, verificando las diferentes formas normales y buscando evitar redundancias y dependencias innecesarias.

El informe detallado del proceso de normalización se encuentra en la carpeta **Informe de Normalización**.
