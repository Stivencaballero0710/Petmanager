## 📌 Segunda Entrega — Modelo Relacional

Esta sección corresponde a la **segunda entrega del proyecto PetManager**, en la cual se presenta el modelo relacional normalizado y el informe correspondiente al proceso de normalización.

El modelo busca representar de manera organizada la información necesaria para la gestión de una veterinaria, manteniendo relaciones claras entre las diferentes entidades y procurando reducir la redundancia y mantener la integridad de los datos.

PetManager organiza información relacionada con **veterinarias, sucursales, inventario, elementos médicos, medicamentos, empleados, clientes, animales, citas, facturación y registros clínicos**.

### 📑 2. Informe de Normalización

En esta carpeta se encuentra el informe que documenta el proceso de normalización aplicado al modelo relacional.

El informe analiza las diferentes formas normales:

- **1FN — Primera Forma Normal**
- **2FN — Segunda Forma Normal**
- **3FN — Tercera Forma Normal**
- **BCNF — Forma Normal de Boyce-Codd**
- **4FN — Cuarta Forma Normal**
- **5FN — Quinta Forma Normal**
- **6FN — Análisis de la Sexta Forma Normal**

Además, se revisan aspectos relacionados con dependencias, redundancia, claves y posibles descomposiciones del modelo.
