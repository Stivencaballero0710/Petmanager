# Actividad de exploración

## Enunciado

La actividad de exploración se organiza alrededor de tres puntos:

1. Identificar los **conceptos importantes y relevantes** de la temática asignada.
2. Consultar las **tendencias actuales** relacionadas con el área del proyecto.
3. Consultar y analizar **herramientas existentes en el mercado** para la gestión de clínicas veterinarias.

**Temática asignada:** sistema de gestión para una clínica veterinaria.
